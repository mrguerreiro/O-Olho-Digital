## Sobre o Projeto

O **O Olho Digital** é o site institucional de uma consultoria especializada em **Inteligência Cibernética e Investigação Digital**. Desenvolvido com foco em clareza, confiança e discrição, o site apresenta os serviços da empresa e oferece um canal direto de contato para clientes que buscam suporte jurídico e tecnológico no ambiente digital.

---

## Serviços Oferecidos

| Serviço | Descrição |
|---|---|
| 🔍 **Identificação de Perfis Falsos** | Detecção e análise de perfis fraudulentos para proteção de imagem |
| 💻 **Investigação de Golpes Online** | Investigação de fraudes digitais com suporte à recuperação de perdas |
| 💔 **Investigação de Adultério** | Apuração discreta e responsável de suspeitas de infidelidade |
| 🗑️ **Remoção de Conteúdos Indevidos** | Exclusão de conteúdos ofensivos e prejudiciais da internet |
| 📍 **Localização de Pessoas** | Rastreamento digital para localização de pessoas desaparecidas |
| 🏛️ **Levantamento Patrimonial** | Identificação de bens e ativos para suporte em processos judiciais |
| 📄 **Dossiês Estratégicos** | Relatórios detalhados como base para decisões jurídicas e corporativas |

## Tecnologias Utilizadas

- **HTML5** — Estrutura semântica e acessível
- **CSS3** — Layout responsivo com design moderno (dark theme)
- **`.htaccess`** — Proteção de segurança do servidor (headers, rate limiting, proteção de arquivos)
- **`robots.txt`** — Controle de indexação e proteção contra bots maliciosos

---

## Segurança

O projeto inclui configurações de segurança avançadas para implantação em produção:

- ✅ Headers HTTP de segurança (`X-Frame-Options`, `X-Content-Type-Options`, `HSTS`)
- ✅ Bloqueio de listagem de diretórios
- ✅ Proteção de arquivos sensíveis (`.htaccess`, `robots.txt`)
- ✅ Rate limiting para prevenção de ataques

## Como Executar Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/mrguerreiro/O-Olho-Digital.git
   ```

2. **Acesse a pasta:**
   ```bash
   cd O-Olho-Digital
   ```

3. **Abra no navegador:**
   ```bash
   # Simplesmente abra o index.html no seu navegador
   start index.html      # Windows
   open index.html       # macOS
   xdg-open index.html   # Linux
   ```

> Para um ambiente mais fiel à produção, use uma extensão como o **Live Server** do VS Code.
